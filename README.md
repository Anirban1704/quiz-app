# React Quiz

A React 19 application scaffold built with Vite.

## Requirements

- Node.js (LTS recommended)
- npm

## Getting started

```sh
npm install
npm run dev
```

Open the local URL printed by Vite in your browser. To create and preview a
production build, run:

```sh
npm run build
npm run preview
```

Run the linter with `npm run lint`.

## Current status

The repository contains the Vite setup, quiz-related styles, and image assets.
The quiz interface and behavior have not been implemented yet; `src/App.jsx`
currently renders no content.
